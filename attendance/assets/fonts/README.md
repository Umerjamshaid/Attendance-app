# Profile Typography

DM Sans is bundled unmodified for offline Profile and Settings text. Other
screens keep their existing typography. Attendance counters retain Inter with
tabular numerals because DM Sans does not provide a `tnum` feature.

- Source: [Google Fonts DM Sans](https://github.com/google/fonts/tree/main/ofl/dmsans)
- File: `DMSans[opsz,wght].ttf`, stored locally as `DMSans.ttf`
- License: [SIL Open Font License 1.1](OFL-DMSans.txt)
- Downloaded: 2026-11-10
- SHA-256: `8cd08d97e89c24d0aa92edd2f0f4c8ee6195eee9b7c9f154865a58b02f0c1c0d`

The variable font supplies weights 100-1000 and optical sizes 9-40. The app uses
the normal readable UI weights, not a second decorative display family.
